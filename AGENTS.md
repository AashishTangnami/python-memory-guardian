# Repository agent instructions

For every change to application code, tests, scripts, build or packaging files, or code-related configuration, read and follow [.agents/skills/maintain-feature-docs/SKILL.md](.agents/skills/maintain-feature-docs/SKILL.md). Complete the corresponding documentation update in the same change. This applies to internal implementation changes as well as user-facing features.

Treat source code as the authority for implemented behavior. Preserve unrelated user changes in the working tree.

For feature work, use [MEMORY.md](MEMORY.md) as a short index and [docs/feature-map.md](docs/feature-map.md) for implementation details. Keep the feature map as the single detailed source of truth; do not copy its diagrams or tables into memory.
