# Python Memory Guardian - runtime dependencies of the Python language server.
#
# These are NOT installed into anyone's environment. `npm run vendor:python` copies
# them into server/libs/, and that folder ships inside the extension. End users only
# need a Python interpreter (3.9+); the probe and the profiler use the standard library.
#
# Rules for this file (each one fixes a real failure):
# 1. Pinned for the OLDEST supported Python (3.9), because the bundle must work on
#    every Python a user might run. uv resolves for the requested target version, so
#    an unpinned build on 3.12 picks cattrs 26.x, which requires Python >= 3.10.
# 2. Complete and without environment markers. cattrs needs exceptiongroup only on
#    Python < 3.11; a resolver evaluates that marker against its target interpreter, so
#    a build on 3.11+ silently omitted it and the server failed on 3.9/3.10 with
#    "No module named 'exceptiongroup'". It is listed unconditionally here; on 3.11+
#    it simply defers to the built-in ExceptionGroup.
# Verified with the server's LSP parity test on CPython 3.9.25, 3.10.20, 3.12.3,
# 3.13.13 and 3.14.4.
#
# To update: change a version, then run `npm run vendor:python && npm test` on the
# oldest and newest supported Python.
